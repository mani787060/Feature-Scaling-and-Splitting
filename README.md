# Feature Scaling and Splitting in Machine Learning

## 📌 Project Overview

This project demonstrates two important preprocessing steps in machine learning: **Feature Scaling** and **Feature Splitting**.

Feature Scaling ensures that numerical features are on a similar scale, preventing features with larger values from dominating the learning process. Feature Splitting involves separating the dataset into independent features (**X**) and the target variable (**y**) before model training.

These preprocessing techniques help create clean, consistent, and model-ready data.
